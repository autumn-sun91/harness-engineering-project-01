# Step 13: landing-and-legal

## 읽어야 할 파일

- `/docs/PRD.md` — Free/Pro 매트릭스, 법적 페이지 요구사항
- `/docs/DESIGN.md` — 랜딩·법적 페이지의 디자인 규칙
- `/docs/ARCHITECTURE.md` — 보안 경계(LLM 전송 범위 — 고지 문구의 근거)
- `/docs/USER_JOURNEY.md` — 1절 여정 진입점
- `/src/app/page.tsx` — step 0의 목업 랜딩 (이 step에서 실제 랜딩으로 대체)
- `/src/app/(dashboard)/` — step 10~12의 화면 (톤·컴포넌트 일관성 유지)

## 작업

1. **랜딩 페이지** — step 0의 목업을 실제 랜딩으로 대체한다.
   - 제품이 무엇을 해주는지 한눈에 보이는 히어로 섹션.
   - 5종 분석(카테고리별 지출, 기간별 추이, 구독 누수·이상 거래, AI 요약, 절약 인사이트) 소개.
   - **플랜 비교표** — `docs/PRD.md`의 매트릭스를 그대로 반영한다. Pro는 $9/월. Free 티저 범위(이상거래 상세 3건, 절약 인사이트 1개)를 정직하게 표기하라.
   - CTA는 `/login`으로 연결한다.
   - `/docs/DESIGN.md`를 따른다. 흰 캔버스 + 무채색 + 포인트 컬러 `#0052ff` 하나. 대시보드와 톤을 맞춘다.
2. **`/privacy`, `/terms`** — 정적 페이지 2장.
   - 개인정보 처리방침에는 **"업로드한 거래 데이터가 분석을 위해 Anthropic API로 전송된다"**는 사실과, 전송 범위(컬럼 매핑용 헤더·대표 행, 분류용 가맹점명, 해석용 집계 통계뿐이며 거래 원본 전체는 전송하지 않음), **원본 CSV를 보관하지 않는다는 사실**, 계정 삭제 시 파생 데이터 파기를 명시한다.
   - 이용약관에는 결제·구독·해지 정책(Polar를 통한 결제, 해지 시 결제 주기 종료까지 이용 가능)을 명시한다.
   - **법률 자문이 아니라 프로토타입용 초안**이며 실제 서비스 전 검토가 필요하다는 점을 `summary`에 남겨라.
3. **고지 노출** — 로그인 페이지 또는 최초 업로드 지점에 "거래 데이터가 분석을 위해 Anthropic API로 전송됩니다"를 짧게 안내하고 `/privacy` 링크를 건다.
4. 푸터에서 `/privacy`, `/terms`로 이동할 수 있게 한다.

## 검증 절차

1. 위 AC 커맨드를 실행한다.
2. 체크리스트:
   - 플랜 비교표가 `docs/PRD.md`와 일치하는가? (Free 월 5회·12개월·티저 범위, Pro $9)
   - LLM 전송 고지가 실제 구현(step 7에서 무엇을 보내는지)과 일치하는가?
   - 랜딩·대시보드의 디자인 톤이 일관적인가?
3. `phases/0-mvp/index.json`의 step 13을 업데이트한다.

## 금지사항

- 플랜 비교표에 구현하지 않은 기능(통합 대시보드, PDF 내보내기, 원본 다운로드)을 적지 마라. 이유: 결제 후 없는 기능을 발견하면 환불 사유가 된다.
- 실제로 보내지 않는 데이터까지 전송한다고 쓰거나, 반대로 전송 사실을 숨기지 마라. 이유: 고지 내용은 구현과 일치해야 한다.
- 블로그, 고객 후기, 가짜 사용 통계 같은 섹션을 만들지 마라. 이유: 없는 실적을 지어내는 것이고 MVP 범위 밖이다.
- 뉴스레터 구독, 문의 폼 등 백엔드가 필요한 요소를 추가하지 마라. 이유: 처리할 곳이 없다.

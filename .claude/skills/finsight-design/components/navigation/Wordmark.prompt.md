Typographic brand mark — use wherever a logo would sit; no logo asset exists in this system.

```jsx
<Wordmark href="/" size={22} />
<Wordmark tone="on-dark" size={22} />
```

- `tone="primary"` (Finsight Blue) on light surfaces, `tone="on-dark"` inside dark bands.
- Always Display weight 400 with -3% tracking; never bold, never all-caps.

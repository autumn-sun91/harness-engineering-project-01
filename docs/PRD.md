# PRD: TxAnalyzer (가칭)

## 목표
사용자가 업로드한 거래내역/카드 명세서 CSV를 Claude API로 분석해, 소비 패턴과 인사이트를 대시보드로 보여주는 핀테크 SaaS. MVP는 "이 제품에 돈을 낼 사람이 있는가"를 검증하는 프로토타입이다.

## 사용자
자신의 거래내역·카드 소비를 분석하고 싶은 개인 사용자 (B2C)

## 핵심 기능
1. 랜딩 페이지 → 로그인 → 대시보드 전환 플로우
2. 로그인/인증 (Supabase Auth, **Google OAuth만** 지원)
3. CSV 업로드 → 분석 → 대시보드 표시
   - 카테고리별 지출 분석
   - 기간별 지출 추이
   - 구독 누수 / 이상 거래 탐지
   - AI 요약
   - 절약 인사이트
4. 결제 (Polar 구독, Free/Pro 두 플랜)
5. 배포 (Vercel)

## 구독 플랜

"본 적 없는 기능은 구매하지 않는다" — Pro 기능을 완전히 잠그는 대신 티저를 보여준다.

| 기능 | Free | Pro ($9/월) |
|---|---|---|
| CSV 업로드 | 월 5회 | 월 30회 |
| 동시 분석 | 1건 | 1건 |
| 데이터 조회 범위 | 최근 12개월 (`recent12m`) | 전체 (`full`) |
| 카테고리별 지출 | O | O |
| 기간별 지출 추이 | O | O |
| AI 요약 | O | O |
| 구독 누수 / 이상 거래 탐지 | 건수 + 상세 최대 3건 | 전체 |
| 절약 인사이트 | 최대 3개 중 1개 | 전체 |

월 한도는 Asia/Seoul 달력 월 기준이다. `recent12m`은 업로드 내 가장 최신 거래일이 속한 달과 직전 11개 달을 뜻하며, 업로드 시점에 고정되므로 시간이 지나도 같은 리포트의 수치가 바뀌지 않는다.

분석 5종은 `recent12m`과 `full` **두 scope로 모두 생성·저장**하고, 조회 시점에 **DB 함수(`get_upload_report`)가 구독 상태를 확인해 허용된 scope와 티저만 반환**한다. 애플리케이션이 전체 payload를 읽어 클라이언트에서 숨기는 방식은 쓰지 않는다. 업그레이드하면 재분석 없이 같은 리포트의 `full`이 즉시 열린다.

전체 여정·엣지 케이스와 다이어그램은 [USER_JOURNEY.md](./USER_JOURNEY.md) 참조.

## MVP 제외 사항
- 특정 은행/카드사 전용 CSV 포맷 파서 (범용 파싱 + LLM 컬럼 매핑 추론만 지원)
- 수동 컬럼 매핑 UI (LLM 자동 추론으로 대체, 실패 시 재업로드 안내)
- 원본 CSV 보관·재다운로드 (메모리에서만 처리하고 Storage·DB에 남기지 않는다)
- 다중 통화 환산 (한 파일에 여러 통화가 섞이면 실패시킨다)
- 여러 업로드를 가로지르는 통합 대시보드
- PDF 리포트 내보내기
- GPT 등 Claude 외 LLM 프로바이더
- 팀/조직 계정, 다중 사용자 협업
- 모바일 네이티브 앱

## 법적 페이지
결제를 받고 금융 데이터를 외부 LLM API로 전송하므로 `/privacy`, `/terms` 정적 페이지를 포함한다. 가입·업로드 지점에 다음을 고지한다.

- 거래 데이터가 분석을 위해 Anthropic API로 전송된다는 사실
- 전송 범위 — 컬럼 매핑용 헤더·대표 행, 분류용 가맹점명, 해석용 집계 통계뿐이며 거래 원본 전체는 보내지 않는다
- 업로드한 원본 CSV를 보관하지 않는다는 사실
